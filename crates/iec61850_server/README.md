# iec61850-cmd-server

Command line for the IEC 61850 server. The binary name is `iec61850_server`.

```sh
cargo install iec61850-cmd-server
iec61850_server version
```

`start` does not open a listener yet. The planned listen path is recorded in `PLAN_server.md` in the repository:

https://github.com/alfred-hong/iec61850-cmd
